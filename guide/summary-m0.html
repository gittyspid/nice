סיכום סשן 1

התחלנו לעבוד עם Claude Code

בסשן התקנו את Claude, חיברנו אותו ל-Git, ראינו אתר דמו לדוגמה, נרשמנו ל-Claude Code ובנינו יחד אתר תדמית ראשוני. ריכזתי כאן הכל כדי שיהיה קל להמשיך.

משך הסשןשעתיים
נושאהקמה ואתר ראשון
תוצראתר תדמית ראשוני

מה עשינו בסשן

  1. 1

    התקנו את אפליקציית Claude

    הורדנו מהאתר הרשמי, התקנו במחשב והתחברנו לחשבון.

    claude.com/download
  2. 2

    התחברנו ל-Git ול-GitHub

    התקנו את Git, התחברנו לחשבון GitHub ויצרנו ריפו ריק לפרויקט. ככה כל עבודה נשמרת בענן עם היסטוריה מלאה.

    git-scm.com github.com/new
  3. 3

    ראינו דוגמה לאתר דמו

    הסתכלנו על אתר שנבנה כולו עם Claude Code, כדי לראות מה אפשר להשיג ואיך נראה התהליך מבפנים.

  4. 4

    נרשמנו ל-Claude Code

    הפעלנו מנוי בתשלום (Pro ומעלה), כי בלעדיו אין גישה ללשונית Code. אחר כך פתחנו את הלשונית ובחרנו תיקייה לפרויקט.

    claude.com/pricing
  5. 5

    יצרנו אתר תדמית ראשוני

    כתבנו פרומפט עם פרטי העסק, ו-Claude בנה את הגרסה הראשונה של האתר. אחר כך ביקשנו תיקונים וראינו את התוצאה בדפדפן.

מה יש לך עכשיו

  • אפליקציית Claude מותקנת ומחוברת
  • Git מותקן וחשבון GitHub פעיל
  • מנוי פעיל ל-Claude Code
  • תיקיית פרויקט עם אתר תדמית ראשוני

הצעדים הבאים

  • להשלים טקסטים, תמונות ולוגו באתר
  • לבדוק את האתר גם בטלפון
  • לבקש מ-Claude: "תעלה את השינויים לגיט"
  • לחבר את הריפו ל-Vercel ולפרסם (vercel.com/new)

להמשך העבודה: פרומפט לדוגמה

אני רוצה מה לשנות או להוסיף באתר. המטרה: למה זה חשוב, מה הגולש צריך להרגיש או לעשות. סגנון: צבעים / תחושה / דוגמה שאהבתי. לפני שאתה מתחיל, תציג לי תוכנית קצרה. אל תעלה לגיט עד שאאשר.
טיפ: כדאי לבקש שינוי אחד בכל הודעה ולבדוק אותו בדפדפן לפני שממשיכים. ככה קל לראות מה עבד ולתקן מהר.
